# 報價資料工廠設計

相關文件：[[2026-08-26_報價資料工廠_SPEC]]、[[2026-08-26_報價資料工廠_PLAN]]、[[2026-08-26_報價資料工廠_CHECK]]

## 架構

`quotationFactory.ts` 提供純資料建構函式；其中 `createEmptyQuotation` 讀取 `localStorage` 的公司與業務員預設值，並依 `quotationType` 建立 items 或 bookletJobs。`App.tsx` 只保留 state 與畫面流程。

## 資料流

使用者切換報價類型 → `createEmptyQuotation(type)` → React state → `QuotationForm` / `QuotationPreview`。每次呼叫均建立新的陣列、物件與 ID，避免 state 共享參照。

## 錯誤處理與測試

factory 不接收不可信輸入；型別由 TypeScript 約束。測試驗證欄位預設值、三種類型的子集合、ID 唯一性與 localStorage fallback。

實作結果：factory 測試 6/6、完整測試 32/32 通過；lint、build 與列印版面檢查均通過。
