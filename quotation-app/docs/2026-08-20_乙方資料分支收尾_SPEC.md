# 乙方資料分支收尾規格

相關文件：[[2026-08-20_乙方資料分支收尾_SDD]] · [[2026-08-20_乙方資料分支收尾_PLAN]] · [[2026-08-20_乙方資料分支收尾_CHECK]]

## 需求

- 依使用者選擇，將 `feat/party-b-data` 在本機整合回 `master`。
- 整合後重新驗證估價單系統。
- 只在分支內容已完整納入 `master` 且功能 worktree 乾淨時進行清理。
- 清理 `.worktrees/party-b-data` worktree 與 `feat/party-b-data` 分支。
- 記錄修改前 Git 備份與實際驗證結果。

## 範圍

- Git 分支祖先關係與工作樹狀態檢查。
- 本機 fast-forward-only 整合檢查。
- 測試、lint、production build 與列印版面驗證。
- Git worktree 與已合併功能分支清理。
- 本次 SPEC、SDD、PLAN、CHECK 文件。

## 非目標

- 不修改乙方資料功能程式碼。
- 不新增 Git remote，不執行 push 或建立 Pull Request。
- 不清理 Vault 內其他 worktree、分支或未追蹤內容。
- 不使用強制分支刪除。

## 契約

- `git merge-base --is-ancestor feat/party-b-data master` 必須成功。
- 功能 worktree 的 `git status --porcelain` 必須為空。
- worktree 絕對路徑必須精確解析為 Vault 內的 `.worktrees/party-b-data`。
- 清理分支必須使用 `git branch -d`，不得使用強制刪除。

## 驗收條件

- [x] 清理前備份 tag 可解析至明確 commit。
- [x] `master` 已包含功能分支的全部 commit。
- [x] 完整驗證命令均以退出碼 0 結束。
- [x] 功能 worktree 已移除。
- [x] `feat/party-b-data` 分支已不存在。
- [x] `master` 與估價單專案內容保持完整。
