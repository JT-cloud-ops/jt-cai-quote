# 報價資料工廠規格

## 需求與範圍

- 將 `App.tsx` 內建立空白報價資料的邏輯抽到 `src/domain/quotationFactory.ts`。
- 提供空白單張、冊子與部門報價資料，以及其子項目 factory。
- 保留目前的預設值、欄位形狀、ID 產生方式與 `localStorage` 預填行為。
- `App.tsx` 改為使用 factory，不改變畫面與流程行為。

## 非目標

- 不修改報價計算、匯入驗證、儲存格式或預覽版面。
- 不新增後端 API 或改變既有使用者資料。

## 驗收條件

- [x] factory 單元測試涵蓋三種報價類型與子項目預設值。
- [x] `App.tsx` 不再持有重複的空白資料 factory。
- [x] 完整測試、lint、build 與列印版面驗證通過。
