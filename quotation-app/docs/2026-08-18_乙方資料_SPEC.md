# 乙方資料需求規格

相關文件：[[2026-08-18_乙方資料_SDD]] · [[2026-08-18_乙方資料_PLAN]] · [[2026-08-18_乙方資料_CHECK]]

## 需求

在估價單系統新增乙方資料，欄位為公司名稱、法代、地址、統一編號、電話、傳真、聯絡人、手機。乙方資料需可輸入、編輯、快速選取、保存於報價歷史、匯入／匯出 JSON，並顯示於預覽與列印的乙方欄位。

## 範圍

- `QuotationData` 新增 `partyB` 物件，集中保存乙方資料。
- 表單提供乙方資料庫搜尋與選取，使用獨立的 `partyBDatabase` localStorage key。
- 儲存報價時以公司名稱為索引新增或更新乙方資料。
- 舊 JSON／歷史資料缺少 `partyB` 時以空白物件相容處理。
- 預覽底部合約雙方區塊將空白乙方改為帶入 `partyB`。

## 非目標

- 不修改既有甲方／客戶資料欄位與 `customerDatabase`。
- 不新增後端或跨裝置同步。
- 不改變金額計算與既有報價類型。

## 驗收條件

1. 新建報價可填寫八個乙方欄位，預覽即時更新。
2. 儲存後重新建立報價，可從乙方資料庫搜尋並一鍵帶入。
3. JSON 匯出包含 `partyB`；匯入可還原欄位。
4. 歷史紀錄保存／載入乙方資料；舊紀錄仍可載入且欄位為空白。
5. 列印預覽的乙方欄位正確顯示，空值不顯示 `undefined`。
6. TypeScript build、lint 與既有列印版面驗證通過。
