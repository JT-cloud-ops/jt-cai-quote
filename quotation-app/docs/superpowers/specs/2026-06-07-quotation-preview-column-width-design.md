# 報價單預覽表格欄寬調整設計

## 目標

調整報價單預覽畫面的表格欄寬，讓單張類、冊子類、百貨類三種報價單都使用一致、比較好閱讀的欄位比例。

目前表格保留 8 個欄位，但「開數、印色、數量、單價」這些短欄位占用太多寬度，導致「其他明細」欄位太擠。這次修改的重點是保留原本欄位，但重新分配欄寬。

## 本次會修改的範圍

- 保留目前 8 個欄位：
  - 印件名稱
  - 開數
  - 印色
  - 用紙
  - 其他明細
  - 數量
  - 單價
  - 金額
- 單張類、冊子類、百貨類都套用同一套欄寬比例。
- 把目前寫在 `QuotationPreview.tsx` 表頭裡的欄寬設定，改成集中管理。
- 加寬「其他明細」欄位。
- 稍微縮小「開數、印色、數量、單價」等短欄位。
- 改善文字換行方式，讓中文、英文、數字不要斷得太難看。
- 保留冊子類與百貨類目前的列合併方式，例如數量、單價、金額使用 `rowSpan` 的呈現方式。

## 本次不會修改的範圍

- 不改表單輸入欄位。
- 不改報價資料格式。
- 不改未稅、營業稅、含稅總計的計算方式。
- 不改公司抬頭、公司資料、發票章、合約條款。
- 不改列印按鈕、JSON 備份、LINE 分享、檔名規則。
- 不合併欄位，也不刪除欄位。

## 建議欄寬比例

報價單表格維持 8 欄，建議比例如下：

| 欄位 | 建議寬度 | 原因 |
|---|---:|---|
| 印件名稱 | 15% | 保持印件名稱可讀，但不要占掉明細空間。 |
| 開數 | 8% | 通常內容較短。 |
| 印色 | 8% | 通常內容較短，特殊色可以換行顯示。 |
| 用紙 | 16% | 紙張名稱有時會比較長，需要比短欄位寬。 |
| 其他明細 | 25% | 這是本次主要要改善的欄位，需要最多空間。 |
| 數量 | 9% | 數字加單位，通常不會太長。 |
| 單價 | 9% | 金額欄位，靠右顯示即可。 |
| 金額 | 10% | 需要顯示金額，也可能附上「含稅 / 未稅」。 |

總寬度為 100%。

## 版面處理方式

表格仍維持 `table-layout: fixed`，這樣列印 A4 時欄位比較穩定，不會因為某一格文字太長就把整張表格撐歪。

建議做法：

- 在 `.quotation-table-main` 表格內加入 `<colgroup>`。
- 每一欄使用有意義的 class 名稱，例如：
  - `quote-col-job`
  - `quote-col-size`
  - `quote-col-color`
  - `quote-col-paper`
  - `quote-col-details`
  - `quote-col-quantity`
  - `quote-col-unit-price`
  - `quote-col-amount`
- 欄寬比例集中寫在 `Preview.css`。
- 移除表頭 `<th>` 裡原本的 inline width 設定。

## 文字換行規則

目前表格儲存格使用 `word-break: break-all`，雖然可以避免文字超出欄位，但中文、英文與數字可能會被切得不好看。

新的處理方式：

- 一般文字欄位使用比較自然的換行：
  - `word-break: normal`
  - `overflow-wrap: anywhere`
- 數字欄位保持緊湊好讀：
  - `white-space: nowrap`
  - 數量置中
  - 單價與金額靠右
- 「其他明細」繼續允許多行顯示：
  - 保留 `white-space: pre-wrap`
  - 內容靠上對齊
- 表頭文字維持置中，除非空間不足才換行。

## 會影響的檔案

### `src/components/QuotationPreview.tsx`

- 移除表頭欄位的 inline width。
- 加入共用的 `<colgroup>`。
- 保留目前單張類、冊子類、百貨類的表格渲染邏輯。

### `src/styles/Preview.css`

- 新增 8 個欄位的欄寬 class。
- 調整表格儲存格的換行規則。
- 讓數量、單價、金額欄位維持好讀的對齊與不換行規則。

## 測試方式

手動檢查：

- 單張類報價單，輸入較長的「其他明細」。
- 冊子類報價單，輸入多個部件，並填入較長的用紙與明細。
- 百貨類報價單，確認「總公司量」仍正常顯示。
- 桌面預覽畫面沒有明顯跑版。
- A4 列印預覽沒有超出頁面寬度。
- 備註列與合計列仍正確跨欄。

建議執行：

```powershell
npm run build
```

如果本機環境造成 build 失敗，就改跑可用的 TypeScript 或 lint 檢查，並把限制說清楚。

## 驗收標準

- 單張類、冊子類、百貨類都使用同一套 8 欄比例。
- 「其他明細」欄位明顯比目前更寬。
- 短欄位變窄後，內容仍可閱讀。
- 冊子類與百貨類的列合併仍然對齊。
- 備註列與合計列仍維持正確跨欄。
- A4 列印預覽不超出頁面寬度。
- 不改變任何金額計算方式。
- 不改變任何已儲存的報價資料格式。
