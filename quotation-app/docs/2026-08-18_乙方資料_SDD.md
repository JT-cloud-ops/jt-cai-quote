# 乙方資料設計

相關文件：[[2026-08-18_乙方資料_SPEC]] · [[2026-08-18_乙方資料_PLAN]] · [[2026-08-18_乙方資料_CHECK]]

## 架構與資料模型

在 `src/types/index.ts` 新增 `Party` 型別，包含 `name`、`representative`、`address`、`taxId`、`phone`、`fax`、`contactPerson`、`mobile` 八個字串欄位；`QuotationData` 新增 `partyB: Party`。

## 資料流

`App` 建立空白 `partyB` → `QuotationForm` 編輯與更新 → 儲存時寫入 `partyBDatabase` → 預覽由 `QuotationPreview` 讀取 `data.partyB`。匯入資料先經正規化，缺少 `partyB` 時補空白值。

## 元件責任

- `App.tsx`：建立初始乙方資料與匯入相容正規化。
- `QuotationForm.tsx`：欄位輸入、資料庫載入／搜尋／選取、儲存乙方資料。
- `QuotationPreview.tsx`：渲染合約區乙方資訊。
- `types/index.ts`：提供共用型別。

## 錯誤處理

localStorage JSON 解析失敗時沿用空陣列；匯入缺少欄位時以空字串補值；選取資料庫項目以不可變更新更新整份報價資料。

## 測試設計

以型別／純函式相容測試驗證空白 Party、舊資料正規化與欄位保存；執行 lint、build、列印版面腳本確認整合未回歸。
